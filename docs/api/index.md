# API Reference

Generated from docstrings. Every function also documents its own parameters, return type,
and — where relevant — the exact formula it computes.

- **[Portfolio](portfolio.md)** — the main entry point.
- **[core](core.md)** — asset-class tagging, calendar alignment, currency conversion, weight
  normalization.
- **[explain](explain.md)** — `Explanation`, `MetricResult`, and the `explain()` dispatcher.
- **[metrics](metrics/index.md)** — every metric function, grouped by submodule: `returns`,
  `risk`, `performance`, `drawdowns`, `rolling`, `distributions`, `benchmarks`,
  `regressions`, `covariance`, `summary`, `costs`.

Not yet implemented (see the [Roadmap](../roadmap.md)): `portpy.visualization`,
`portpy.models`, `portpy.strategies`.
